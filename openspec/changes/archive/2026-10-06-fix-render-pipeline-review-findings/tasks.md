# Tasks

Toutes les commandes Rust passent par `nix develop -c cargo …`. Les sondes de la relecture (`scratchpad/p2/src/main.rs`, modes `thr`, `dots`, `linkcol`, `doc`) servent de point de départ aux tests ; elles ne sont pas versionnées. Les tests de pile tournent sur un fil créé par `std::thread::Builder::new().stack_size(2 * 1024 * 1024)` (taille des workers Tokio) : avec les bornes en place, la profondeur de récursion ne dépend plus de l'entrée, donc ces tests sont valables en debug comme en release ; la tâche 9.2 les relance aussi en `--release`.
